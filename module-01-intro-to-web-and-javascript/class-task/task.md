# Class Task — Module 1: Intro to the Web & JavaScript

---

## In-Class Task

**Context:** You have been given a plain HTML page for Publica Academy. It has a heading, a paragraph, and a button — but nothing works yet. Your job is to connect JavaScript to the page and make it respond.

**What to do:**

1. Open `starter.html` in VS Code.
2. Add a `<script>` tag that links to `starter.js`. Place it in the right location in the HTML file.
3. In `starter.js`, write a `console.log` that prints a message when the page loads.
4. Using JavaScript, find the button on the page and make it respond to a click. When clicked, change the heading text to anything of your choice.
5. Open the page in Chrome. Open the Console (F12). Confirm your log appears and your button works.

**Files:** `starter.html`, `starter.js`

---

## Take-Home Task

**Context:** Build a personal introduction page for yourself as a Publica Academy student. The page should be built with HTML, CSS, and JavaScript working together.

**What to do:**

1. Create a new folder called `my-intro-page`.
2. Inside it, create `index.html`, `style.css`, and `script.js`.
3. The page should display your name, a short bio, and a button.
4. Use JavaScript to write your name and a greeting into the page when it loads — do not hard-code them in the HTML.
5. The button should change something visible on the page when clicked. You decide what changes.
6. Open the Console and use `console.log` to prove JavaScript is running.

**Deliverable:** A working folder with all three files.
